# 🛒 SmartCart AI

> An AI-powered shopping assistant currently under development.

## 📖 About

SmartCart AI is a full-stack web application that helps users compare product prices, analyze reviews using AI, and discover the best products based on their budget and preferences.

This project is currently under active development.

## 🚀 Tech Stack

- React + Vite
- Java 21
- Spring Boot
- PostgreSQL
- Python (FastAPI)
- Hugging Face

## 🚧 Project Status

Currently in the **Planning Phase**.
